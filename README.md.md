# City Phone - Sistema de Gestión

Este es el sistema de gestión interna diseñado para **City Phone**, tu local de accesorios y servicios técnicos ubicado en Av. Corrientes.

## Descripción del Proyecto
Este sistema permite la gestión integral del local, incluyendo:
*   **Tracking de ventas**: Registro diario de transacciones.
*   **Gestión de inventario**: Control de stock de accesorios (cables, fundas, auriculares).
*   **Servicio técnico**: Seguimiento de reparaciones y estados de equipos.

## Tecnologías Utilizadas
*   HTML5 / CSS3 / JavaScript
*   Supabase (Persistencia de datos y sincronización en la nube)
*   Vercel (Despliegue y hosting)

## Instrucciones de uso
1. Clonar el repositorio.
2. Instalar dependencias necesarias (si aplica).
3. Configurar el archivo `.env` con las credenciales de Supabase (nunca subir este archivo).
4. Ejecutar el proyecto para el entorno local.
